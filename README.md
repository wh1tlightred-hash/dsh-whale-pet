# 鲸伴 · dsh 鲸鱼娘桌宠

独立的 Windows 透明悬浮桌宠，用于 DeepSeek Harness 桌面客户端。一个鲸鱼娘汇总多个项目/会话，显示真实任务状态，在桌宠中批准一次或拒绝操作，并以静音气泡提示任务完成、失败或中断。

## 使用

- dsh 桌面客户端启动后，桌宠自动出现在屏幕右下角。拖动人物移动位置。
- 任务完成等提醒出现 4 秒后若未操作会自动渐隐，鼠标停在提醒上时暂停计时。
- 点击展开项目栏中的已完成项目，会确认这一次完成提醒并恢复待机；下次任务完成仍正常提醒。
- 双击项目卡片会唤起 DSH，并打开这张卡片对应的对话。单击仍用于选中或取消选中、确认完成；双击不会新建对话或发送消息。
- 待机时每隔约 10–24 秒随机左右张望、点头，或从身后偷偷拿出一碗白饭吃几口；平时每隔约 3–7 秒眨眼一次。工作、审批或回答问题会中断待机动作，尊重系统减少动画设置。
- **Ctrl + 单击打开 DSH**：按住 Ctrl 用左键点鲸鱼娘，会把 DSH 窗口调到最前面（最小化时还原，藏在托盘时重新显示，窗口已关闭时重新打开），不会拖动桌宠。实现上是再启动一次 DSH 自己的程序：DSH 只允许单实例运行，新进程会立刻退出，由正在运行的 DSH 显示自己的窗口。
- **站在屏幕底边**：拖到接近屏幕底部（脚离底边约 48px 以内）松手，鲸鱼娘会落下、双脚正好踩在屏幕工作区的底边上；之后展开项目栏、切换状态都保持站立。
- **屏幕边缘探头**：将人物拖到当前屏幕工作区的左侧或右侧并松手，会收起项目栏并贴边探头。拖回屏幕内恢复正常形象；双击探头可恢复并展开项目栏。探头时鼠标移到鲸鱼娘上，项目卡片会渐显在头顶偏向屏幕内侧的位置（贴左边时在头的右上方，贴右边时在左上方），没有项目时显示状态气泡；点击卡片会恢复桌宠、展开项目栏并选中该对话。新的审批、提问或完成提醒会先恢复到屏幕内，确保信息可见。参考 [dsh-pet-indesktop 的边缘探头行为](https://github.com/MerZlin/dsh-pet-indesktop/blob/main/pet/edge_probe.py)，使用独立生成的鲸鱼娘探头素材。
- **模型提问**：模型向你提问（ask_user_question，例如「你想查哪座城市的天气？」）时，桌宠自动展开并显示问题卡片：单选题点击选项即回答，也可输入自己的回答；多个问题或多选题选好后点「提交回答」。dsh 窗口里的问题卡片同时可答，哪边先回答就用哪边。
- **发起新对话**：鼠标移到桌宠上时，左腿旁会渐显新对话图标，移开后渐隐；点击图标展开为对话栏（DeepSeek 标志 +「今天有什么可以帮您的？」），对话栏完全展开后，其上方渐显工作区选项（「📁 工作区 ⌄」），默认为最近对话所在的工作区，选择会被记住；输入后按回车即在所选工作区中新建会话并发送这条消息（没有工作区时用 dsh 的默认目录）；若先在项目栏中点选了某个对话（卡片高亮，对话栏显示「回复「…」」），则消息发到该对话继续，再点一次取消选择，新会话会出现在 dsh 会话列表和桌宠项目卡片中。Esc 收起。展开项目栏时对话栏常显示在桌宠左侧；桌宠靠近屏幕左边缘、左侧放不下对话栏时，图标和对话栏会镜像显示在桌宠右侧。按住拖动仍是移动桌宠。
- 点击状态卡片展开或收起项目列表，点击项目切换关注对象。右键鲸鱼娘弹出菜单：**置顶**（勾选项，每次启动默认置顶）、**隐藏桌宠**。展开窗口宽 300px，高度随任务数量和审批内容增减，超出屏幕高度时面板内滚动。
- dsh 客户端 **设置 → 桌宠** 是桌宠的专属设置页：**显示桌宠** 开关、**桌宠昵称**（默认「蓝色大肥鱼」，最多 20 字，显示在状态卡片和托盘提示中，清空恢复默认），以及 **桌宠大小** 滑块（60%–160%，拖动后立即缩放，**恢复默认** 回到 100%）。开关桌宠也可以点侧栏底部的 **更多**（登录后为账号名）选择 **隐藏桌宠 / 显示桌宠**；托盘图标右键菜单的 **隐藏桌宠 / 显示桌宠**（左键单击隐藏中的托盘图标也会显示）写入同一个开关，各处状态始终一致。隐藏时窗口消失、不再弹出提醒，托盘图标保留以便重新显示，待处理审批交回 dsh 原生界面；已加载的窗口在后台待命，再次显示是即时的。dsh 启动时开关为关闭则不启动桌宠。开关值写入 profile 的 `cordis.patch.yml`（条目 `desktop-whale-pet` 的 `enabled`）。
- 有审批申请时自动展开，显示所属项目、申请原因和具体操作；每次点击只影响对应申请。
- 展开后没有面板外框：本次 dsh 启动后运行过的项目（含其子智能体）以悬浮卡片列在桌宠头顶上方，桌宠在展开和收起时大小一致，有审批时附审批卡片；没有运行过的历史会话不显示。
- 完全静音；自动出现使用 `showInactive()`，不抢正在输入的焦点。主动点击后可正常操作。
- dsh 关闭、插件卸载或宿主连接断开时，桌宠退出。dsh 保持开启而任务结束时，桌宠保留待机。

## 本机安装

要求 Windows、PowerShell 7、Node.js，以及 dsh desktop profile。本机已按安装版本 `0.2.1-rc.2` 的源码接口适配。

```powershell
pwsh -File .\scripts\install.ps1
```

安装器将此源码目录通过目录联接注册到 `~/.dsh/profiles/desktop/node_modules/dsh-whale-pet`，向 desktop profile 添加 bundle，并备份原 `package.json`。源码目录需要保留，不要在安装后移动它。此安装为本地 link 依赖，未向公共插件市场发布。

桌宠使用独立 Electron 运行时，不修改 dsh 的应用包。本机运行时放在 `.runtime/electron`；安装器可从本机 Electron ZIP 缓存解压。其他机器需自行准备该目录，或设置 `DSH_WHALE_ELECTRON` 指向 Electron 可执行文件。运行时不包含在 npm 插件包中。

安装后重新启动 dsh 桌面客户端。卸载：

```powershell
pwsh -File .\scripts\install.ps1 -Uninstall
```

卸载仅删除本插件的配置与联接，保留源文件。窗口位置及诊断文件位于 `.local/`。

## 审批与状态行为

状态来自 dsh 的会话、工具与智能体事件，不猜测完成百分比。工具名和结构化命令决定“读取文件”“修改文件”“运行测试”等简短提示。项目显示工作目录名及会话标题，同一目录中的不同会话分别列出。

桌宠就绪后才接管审批；尚未启动、启动失败或断开时由 dsh 原生审批界面处理。通过随机命名管道及每次启动随机认证令牌连接本地宿主；不监听 HTTP 端口。审批绑定随机请求 ID，取消或已处理的请求不能再次授权。审批审计仍由 dsh 自身记录。前端没有 Node 权限，项目文本只作为文字渲染。

当前只接入 desktop profile；不会汇总独立命令行启动的 dsh。没有额外常驻服务或开机启动项。鲸鱼娘基于用户提供的形象参考生成透明动作帧，结合定时序列与 CSS 播放，并非 Live2D 模型，也不是 DeepSeek 官方角色。待机动作提示词见 [assets/winter/IDLE-ACTIONS-PROMPTS.md](assets/winter/IDLE-ACTIONS-PROMPTS.md)，眨眼提示词见 [assets/winter/BLINK-PROMPT.md](assets/winter/BLINK-PROMPT.md)。

## 验证与演示

```powershell
node --test test/*.test.js
node scripts/smoke.js
node scripts/demo.js
```

`smoke.js` 启动隐藏的 Electron 窗口，验证多项目、审批回传、文字注入防护、完成提醒、展开高度随内容伸缩及收起尺寸，结果写入 `.local/smoke-result.json`。`demo.js` 打开标明演示模式的桌宠；审批仅改变测试状态，不会执行命令。按 Ctrl+C 退出演示。

独立打开 `ui/index.html` 可以预览界面，浏览器预览不具备真实桌面悬浮或审批能力。

实现参考：本机 dsh 的 `dsh-session`、`dsh-agent`、`dsh-user-approval` 源码，以及 [Electron BrowserWindow 文档](https://www.electronjs.org/docs/latest/api/browser-window)。
